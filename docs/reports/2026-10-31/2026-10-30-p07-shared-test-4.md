## TOCTOU và hồi quy AC2

Đọc `failure()` hiện tại: sau khi kiểm prototype, `Object.getOwnPropertyDescriptors()` lấy snapshot. `Reflect.ownKeys()` duyệt cả khóa Symbol và thuộc tính không enumerable; mỗi descriptor phải có khóa chuỗi, `enumerable: true`, own `value` và giá trị chuỗi. `Object.fromEntries()` dựng bản sao từ descriptor đã kiểm, không đọc lại hay spread `fieldErrors` đầu vào. Kiểm trực tiếp trên bản build `packages/common/dist/index.js` bằng `node -e` dùng `assert` có exit 0:

| Trường hợp | Kết quả thực tế |
| --- | --- |
| Getter lần đầu chuỗi, lần sau số | `TypeError`; getter được gọi **0** lần. |
| Getter luôn trả chuỗi | `TypeError`. |
| Getter có side effect | `TypeError`; bộ đếm side effect vẫn **0**. |
| Setter-only | `TypeError`. |
| Accessor không enumerable | `TypeError`; getter không chạy. |
| Data property hợp lệ, `{}`, null-prototype object hợp lệ | Được nhận; giá trị sao chép chính xác, `error` và `fieldErrors` đều frozen. |
| Khóa riêng `"__proto__"` có giá trị chuỗi | Được giữ như own property; prototype của kết quả vẫn là `Object.prototype`; `fieldErrors` frozen. |
| `Date`, `Map`, `Set`, `Array` | Từng trường hợp ném `TypeError`; không bị biến thành `{}`. |
| Symbol key giá trị chuỗi/số, Symbol không enumerable | Từng trường hợp ném `TypeError`. |
| String key không enumerable; field value số; custom prototype | Từng trường hợp ném `TypeError`. |
| `null`, `undefined`, số, chuỗi, boolean | Từng trường hợp ném `TypeError`. |
