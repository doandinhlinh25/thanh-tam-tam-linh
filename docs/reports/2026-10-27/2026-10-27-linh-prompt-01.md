# Prompt 01 — kiểm chứng upload PDF xuyên service

**Ngày:** 2026-10-27
**Kết luận:** **DONE** cho mốc upload trực tiếp Document + Auth/Tenant.
**Bằng chứng chi tiết:** [báo cáo Test](2026-10-26-linh-upload-e2e-test.md).

## Mục tiêu và phạm vi thực tế

Đã dựng sandbox cô lập, tạo course thật và phiên lecturer/student qua Auth/Tenant, rồi gọi trực tiếp Document với PostgreSQL, private S3 và Redis thật. Mốc đạt được là HTTP 202 và trạng thái `QUEUED`; chưa có worker, `READY`, retrieval, Chat hoặc public gateway E2E.

## Thay đổi

- `infrastructure/sandbox/compose.yaml`: sửa `mongosh --nodb`, thêm mạng `access` cho các service publish cổng localhost; database chỉ ở mạng internal.
- `.gitattributes`: giữ `infrastructure/sandbox/s3-init.sh` ở LF để `/bin/sh` chạy được khi checkout trên Windows.
- `test/sandbox-config.test.js`: kiểm tra bootstrap và ranh giới mạng/cổng.
- `scripts/sandbox-smoke.mjs`: ký S3 request có query string; `scripts/sandbox-upload-e2e.mjs`: kiểm U1–U7 và snapshot tác dụng phụ.
- `package.json` và `infrastructure/sandbox/README.md`: thêm lệnh và hướng dẫn chạy bài kiểm tra.
- Không thay API, schema database hoặc service authorization.

## Trạng thái công việc

| Mã | Trạng thái | Bằng chứng |
| --- | --- | --- |
| P1 | PASS | Sandbox start; Auth/Tenant/Document healthy; fixtures cho lecturer 200 và student 403. |
| P2 | PASS | Dùng Document direct `127.0.0.1:18080`, course và session từ fixture riêng; run ID mới mỗi lượt. |
| P3 | PASS | `npm run sandbox:upload-e2e` dùng HTTP và dependency thật, không mock. |
| P4 | PASS | U1–U7 đạt hai lượt liên tiếp; chi tiết ở báo cáo Test. |
| P5 | PASS | Lỗi Mongo bootstrap, S3 shell CRLF và binding host đã được xác định/sửa trong sandbox; không sửa Auth/Tenant để ép test xanh. |
| P6 | PASS | Tài liệu này bàn giao trạng thái HTTP, `QUEUED` và giới hạn mốc cho frontend/Chat. |

| Ca | Trạng thái | Kết quả chính |
| --- | --- | --- |
| U1 | PASS | 202; thêm 1 row/job/object/event, bytes và checksum đúng. |
| U2 | PASS | 401; không thêm tác dụng phụ. |
| U3 | PASS | 403; không thêm tác dụng phụ. |
| U4 | PASS | 202 và cùng document ID; không tạo thêm dữ liệu. |
| U5 | PASS | 409; không tạo thêm dữ liệu. |
| U6 | PASS | Header giả không nâng quyền hoặc thay danh tính đã xác minh. |
| U7 | PASS | Tenant ngừng đáp ứng cho 503; không ghi dữ liệu; Tenant được khởi động lại và ready. |

## Lệnh và giới hạn

`npm ci`, `node --test test/sandbox-config.test.js`, `npm run sandbox:init`, `npm run sandbox:check`, `npm run sandbox:up`, `npm run sandbox:fixtures`, `npm run sandbox:smoke`, `npm run sandbox:upload-e2e`, `npm run build`, `npm run typecheck`, `npm test` và `.\\mvnw.cmd test` trong Document Service đều đạt sau khi sửa các lỗi nêu trên. Tổng test được ghi nhận: 22 Node và 17 Java. Không có bằng chứng cho ingestion tới `READY` hoặc luồng qua gateway. Sandbox đang chạy, dữ liệu thử được giữ lại; không commit hoặc push.

**Bàn giao tiếp:** mốc upload đã kiểm chứng. Bước kế tiếp của Document là worker xử lý Redis event, cập nhật trạng thái và retrieval theo các prompt sau; việc đó cần kế hoạch/contract riêng.
